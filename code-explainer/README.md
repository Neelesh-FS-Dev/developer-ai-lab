# AI Code Explainer

A prototype project exploring how large language models can help developers understand source code.

## Planned functionality
- Accept a code snippet.
- Explain the code in simple language.
- Generate documentation suggestions.

## Current status
Prototype planning. Implementation has not started.

## Planned technology
TypeScript and an LLM API.

## Development notes
The implementation, supported languages, and API provider will be documented as development progresses.
